## 🚀 部署至 GitHub Pages 指南

若欲將本專案建立為獨立的 GitHub 倉庫並開啟 GitHub Pages：

```bash
git init
git add .
git commit -m "feat: Initial commit for Masa Hsin-Lung Tu Engineering Portal Hub"
git branch -M main
git remote add origin https://github.com/SinLiongToo/<YOUR_REPO_NAME>.git
git push -u origin main
```

在 GitHub 倉庫設定中：
進入 **Settings ➔ Pages ➔ Source 選擇 `Deploy from a branch` ➔ Branch 選擇 `main` / `root` ➔ Save** 即可發布！
